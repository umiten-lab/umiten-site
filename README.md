## 海点とは

**海点（UMITEN）** は、気象・海洋の数値予報とポイントごとの海岸条件を組み合わせ、サーフィンのための波の状態を推定するプロジェクトです。

沖の波高だけでは、岸でどのような波が割れるかは決まりません。波向・周期・風・地形などを踏まえて、**「どこで、いつ、どんな波が期待できるか」** を分かりやすく伝えることを目指しています。

> **DATA × OCEAN × SURFING**  
> 海を読む。もっと自由に。

## 対応サーフポイント

現在は茨城県沿岸の次の5ポイントに対応しています。表示順は北から南です。

1. **大貫つるかめ**
2. **大貫海の子**
3. **大竹海岸**
4. **濁沢**
5. **とっぷさんて**

各ポイントの緯度・経度、海岸の代表方位、水深・波高補正係数は [`points.json`](points.json) に定義しています。**座標・海岸方位・補正係数の一部は公開資料から求めた暫定設定**で、砂州の形状や堤防による遮蔽などは十分に反映していません。

### 総合スコアの考え方

総合スコア（0〜100点）は、**岸の推定波高、面の整い具合、周期、風向・風速**を使う経験的な指標です。面の整い具合には過去24時間の風履歴を考慮しています。ショートとロングのサイズ適性・風向適性は別々です。

2026年11月2日の変更：**波高区分ごとの点数上限を撤廃し、サイズが小さいことによる乗算減点も緩和**しました。スネ〜モモなどのサイズ表示は実際の波高の目安であり、評価記号を直接決定する閾値ではありません。ロングはヒザ〜モモでも、良い面と風・周期が揃えば△や○が出る場合があります。ほとんど波がない場合は波の存在を表す連続係数で減点します。波高自体の推定方法や地点別波高係数は変更していません。

**採点について（暫定・経験的モデル）**：波高だけで「ヒザだから×」「コシだから△」と判定しません。ショートはハラ〜カタを高めに評価しつつ、コシ〜アタマにも適性を持たせ、ロングはヒザ〜モモの小波でも風が穏やか・面が整う条件なら△以上の可能性を残します。サイズによるハードな得点上限をなくし、波高適性・風向・風速・風履歴による面の状態・周期を連続的に組み合わせる方式です。実質ほとんど波がない状況では連続的な減点を行います。◎○△▼×の境界値は維持します。

2026年10月31日のとっぷさんての現地情報（ムネ前後・西風）を参考に、**ショートの6〜8秒周期の評価を連続化**しました。7秒の周期は従来の3点から5点へ変わりますが、**8秒未満では総合69点（△）を上限**としています。これにより、サイズ・面・風がある程度良ければ△に届く余地を残し、○は依然として良条件が揃ったときだけの評価です。周期や面の実測値がないため、同日の総合点そのものを確定するものではありません。

**夜間について**：日没後も波の総合評価を×に変更せず、予測された波質の点数を表示します。ただし暗い時間帯は「おすすめ」から除外し、現在のコメントで入水を勧めない旨を案内します。

「おすすめ」は予報スコアと連動しており、△（55〜69点）も候補に含めます。▼（40〜54点）は「多少できるかもしれない」状態として評価を残しますが、積極的なおすすめ枠には含めません。**その日の最高点を待つのではなく、今後最初に△以上となる時間帯を案内します。**連続する△以上の時間を区間として表示し、区間の最高点は参考として添えます。日の出15分後〜日没15分前に、少なくとも15分以上の明るい時間が残る場合を対象とし、日没後の高得点はおすすめしません。

### 面の状態を推定する時間応答モデル v2

風がオフショアに変わった直後に面が突然最高の状態になるとは限らず、また強いオンショアが吹き始めても実際の海面には時間的な変化があります。

そこで海点では、**直近1日分のモデル予報による風履歴**を含む時系列を用い、各時間帯の「面が向かう状態」と現在の「推定面状態」を分けて計算します。

\[
Q_{t+\Delta t}=Q_{\mathrm{eq}}+(Q_t-Q_{\mathrm{eq}})\exp(-\Delta t/\tau)
\]

- `Q`：面の整い具合（0〜1。1に近いほど整っている）。
- `Q_eq`：その風・波の条件が続いた場合に向かう面の状態。
- `τ`：面が荒れる／整う速さを決める時定数。オンショア・オフショアの強さ、風波の割合、うねり周期などから補正。

荒れるときと回復するときで異なる基準時定数を持たせ、**強いオンショアでは荒れやすく、風が収まった後は徐々に整う**ようにしています。無風でもゼロ除算や不自然な即時変化を起こさない構成です。

このモデルは**経験則による暫定推定であり、海面状態を直接観測したものではありません**。風の履歴は実際の現地観測ではなく、Open-Meteoから取得した過去期間のモデル予報値です。係数は今後、現地記録や観測と照合して調整する必要があります。

### 岸の波高の推定

沖の波浪を、うねり・二次うねり・風波などに分け、**線形波理論による浅水変形と屈折**を簡易的に計算して岸の波高に換算します。等深線が岸と平行であるなどの仮定があり、砕波・複雑な地形・人工構造物の影響は完全には再現できません。

**大貫海の子と大貫つるかめのサイズ差**：海の子の波がつるかめより少し大きくなりやすいという現地情報を参考に、海の子の波高補正係数 `scale` を暫定的に `0.75 → 0.79`（約5.3%増）としました。方位差による屈折計算も残しているため、海の子の波高を常時つるかめより高くする処理ではありません。係数は両地点同時刻の現地波高記録で検証・調整します。

### コシのショート評価を小幅に調整（2026-11-02）

大貫つるかめの現地情報として「コシくらい」との報告を受け、**波高の推定係数は変更せず、ショートボードのサイズ適性だけ**を試験的に微調整しました。コシ0.70〜0.90 mの中間（0.80 m）に限り適合度を最大+0.06、0.70 mでの総合点のサイズ上限を55→59点に変更しています。**0.70 m未満・0.90 m以上とロングのサイズ適性はそのまま**。○を容易に出す変更ではなく、周期・面・風向による減点や上限も維持します。

これは実際の波の良否を測定した校正ではありません。現地の「コシ」という目視サイズだけでは総合スコアの正解は決められないため、実際の予報の岸波高・周期・風・面推定値との照合を続けます。

### とっぷさんての岸波高の暫定補正（2026-11-01）

とっぷさんてで2026年10月31日・11月1日に現地報告（ムネ前後〜ムネ・カタ、西風）があり、当サイトの予報サイズが小さめだったことから、同地点の岸波高補正係数 `scale` を **0.75 → 1.00** に変更しました。ほかの4ポイントの係数は変更していません。**採点式を直接変更したわけではなく、推定岸波高の変更が総合スコアに伝わる**仕組みです。

この変更は**2日分の現地報告に基づく試験的な設定**であり、目視の波サイズとモデル上の推定有義波高の定義も異なるため、予測精度の保証や検証済み係数ではありません。継続して地点別に校正します。

### ウェット指数

指数は**0が軽装寄り、100が高い保温性を要する目安**です。その日の入水可能な日中の予報から、気温と海水温の40パーセンタイル、風速の70パーセンタイルを用います。装備区分のしきい値は、気温・水温の参考範囲の暖かい側80%付近を目安にしています。

気温・水温・風の合成温度とウェットの切り替え基準は、2026年11月1日に暑すぎる推奨を減らすため暫定調整しました。

**気温・水温・風から求める独自の参考値**であり、実測の体感温度や防寒性能を保証するものではありません。日射、運動量、体質、入水時間、ウェットの厚み・状態などでも適切な装備は変わります。

## データの出典と更新

- [Open-Meteo Marine API](https://open-meteo.com/en/docs/marine-weather-api) — 波高・周期・波向、うねり・風波、海水温、海面高度など。
- [Open-Meteo Weather API](https://open-meteo.com/en/docs) — 風向・風速・突風（取得できる場合）、気温、天気コードなど。風は利用可能な場合に**JMA Seamless** を優先し、不足する場合は別モデルに切り替えます。
- [気象庁](https://www.jma.go.jp/) / [NOWPHAS](https://www.mlit.go.jp/kowan/nowphas/) — 気象・波浪の参考情報。現行のスコアへの常時自動同化を意味するものではありません。

予報の海面高度は**平均海面を基準としたモデル値**です。港の検潮所の実測潮位そのものではありません。**潮名は新月を基準にした日本の旧暦日付からの暦上の目安**（地方・潮見表で若干の差があります）で、モデル潮位の干満差から判定したものではありません。**月齢は日本時間の正午**の新月からの経過日数を天文学的な近似計算で表示します。また、APIの参照格子点は実際のサーフポイント座標と一致するとは限りません。

サイトは **GitHub Pages** で公開し、**GitHub Actions** による定期実行（設定上は約3時間ごと）で Python が予報JSONを更新します。実行間隔やデータ更新は配信側・GitHub側の状況に左右されます。

```text
Open-Meteo Weather API / Marine API
                ↓
      Python: scripts/forecast.py
      ・各ポイントの岸波高推定
      ・風履歴に基づく面の時間応答
      ・ショート／ロング別スコア
                ↓
       docs/data/forecast.json
                ↓
     docs/index.html（GitHub Pages）
                ↓
          PC / スマートフォン
```

## 開発・検証の方針

海点は**開発・検証中の独自モデル**です。今後は、ポイントごとの位置・海岸方位・補正値の精査、波浪観測値や現地記録との比較、面の回復・悪化時定数の校正、予報誤差や信頼度の評価を進めます。

## ご利用にあたって

> **海点の表示値は参考予報であり、安全性を保証するものではありません。** 予測と現地の波にはずれが生じます。離岸流、急な気象変化、障害物、海底地形、遊泳・入水規制なども確認し、現地の安全情報と自身の技量を優先してください。
